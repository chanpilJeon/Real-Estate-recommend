# 추천 기준과 검증 범위

Step 7의 초기 정책입니다. 사용자가 평가한 추천 품질(M5)은 별도로 확인해야 합니다.

| 프리셋 | 가격 | 유동성 | 입지 | 단지품질 |
|---|---:|---:|---:|---:|
| 가성비형 | 50% | 20% | 15% | 15% |
| 입지우선형 | 15% | 10% | 60% | 15% |
| 신축선호형 | 15% | 10% | 15% | 60% |

- 먼저 지역·면적·예산·연식·세대수 하드 필터를 적용합니다. 모든 후보를 점수화한 뒤 페이지를 나눕니다. 동점은 단지 ID 순으로 정렬합니다.
- 가격: 최근 6개월 이상치 제외 매매 중위가의 예산 상한 대비 여유 비율. 저평가나 시장 내 백분위를 뜻하지 않습니다. 면적 조건이 없으면 여러 면적의 대표 중위가이므로 비교 전에 원하는 면적을 설정하는 편이 적절합니다.
- 유동성: DB에 수집된 최근 12개월 거래수 / 세대수. 10%를 만점으로 제한한 초기 규칙입니다. 거래 공개·수집 누락이 있으면 실제 회전율과 다릅니다.
- 입지: 지하철역 직선거리(1.5km에서 0점) 70% + 초등학교 직선거리(1km에서 0점) 30%. 실제 보행 경로나 통학구역이 아닙니다.
- 단지품질: 기존 complex 도메인의 규모 35% + 연식 40% + 주차 25% 정책을 재사용합니다. 신축형은 이 품질 지표 전체를 강조하므로 연식만 보는 정렬과는 다릅니다.
- 미상 항목은 50점(중립)이며 `missingData`에 표시합니다. 알려진 낮은 점수보다 유리해질 수 있으므로 미확인 정보가 많은 단지는 직접 확인해야 합니다.
- 차트는 같은 전용면적의 최근 36개월 자료로 서버에서 계산합니다. 취소 거래와 전체 기간 중위가 대비 ±40% 이상치는 통계에서 제외하고, 거래가 없는 달은 0원으로 채우지 않습니다. 최근 목록의 200건 제한은 통계에 적용하지 않습니다.
- 전세가율은 같은 전용면적의 최근 6개월 전세 보증금 중위가 / 매매 중위가입니다. 월세가 있는 계약은 제외하며 자료가 없으면 null입니다.

입지 수집은 카카오 카테고리 검색의 페이지 끝까지 읽고 SC4 중 초등학교만 사용합니다. 이름을 통한 학교 구분에는 한계가 있습니다. [카카오 공식 API 문서](https://developers.kakao.com/docs/ko/local/dev-guide#search-by-category).

자동 검증은 프리셋별 순위 변화·누락값·0 예산·전체 후보 랭킹·200건 초과 통계 보존을 다룹니다. 브라우저 검증은 PC·모바일의 검색/상세/추천 조건 유지와 실제 API 연결을 분리합니다. 이 검증만으로 외부 원천 데이터와 모든 거래가 일치한다고 보장하지 않습니다.
