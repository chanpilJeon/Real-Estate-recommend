# 테스트 체크리스트 (비기술자용)

> 개발이 한 단계 끝날 때마다, 아래 해당 단계의 표를 위에서부터 하나씩 확인합니다.
> **터미널을 읽을 필요는 없습니다.** 화면에 보이는 것만 보고 O/X 를 적으면 됩니다.
> X 가 하나라도 나오면 그 줄을 그대로 개발자에게 전달해 주세요.

---

## M1 — 프로그램이 켜지는가 (Step 0 완료 시점)

**하는 방법**: `scripts` 폴더의 `start.command` 파일을 **더블클릭**합니다.
(검은 창이 하나 뜨고, 잠시 뒤 브라우저가 자동으로 열립니다. 검은 창은 닫지 마세요.)

| # | 확인할 것 | 합격 기준 | 결과 (O/X) | 메모 |
|---|---|---|---|---|
| 1 | 검은 창에 빨간 `✗` 표시가 없다 | 초록 `✓` 만 보인다 | | |
| 2 | 브라우저가 자동으로 열린다 | `localhost:3000` 주소가 열림 | | |
| 3 | 화면에 큰 제목이 보인다 | "지역명 하나로…" 문구가 보임 | | |
| 4 | **웹 화면** 카드 | 초록색 `정상` 배지 | | |
| 5 | **API 서버 연결** 카드 | 초록색 `정상` 배지 | | |
| 6 | 화면 글자가 깨지지 않는다 | 한글이 정상 표시 | | |
| 7 | 휴대폰 크기로 줄여도 괜찮다 | 브라우저 창을 좁혀도 가로 스크롤이 안 생김 | | |

> 5번이 빨간색이면: API 서버만 안 켜진 것입니다. 검은 창의 마지막 10줄을 복사해 전달해 주세요.

## M7 — 운영 상태를 알 수 있는가 (Step 9 완료 시점, 매일 30초)

`/admin` 에 로그인한 뒤 위에서부터 3가지만 봅니다.

| 보는 곳 | 정상 | 이상하면 |
|---|---|---|
| 서버 상태 4칸 | 모두 초록 | 빨강이 있으면 스크린샷 전달 |
| 최신 실거래 계약일 | 오늘 기준 3일 이내 | 3일 넘게 멈춰 있으면 즉시 알림 |
| 최근 로그/에러 | ERROR 없음 | ERROR 메시지 복사해 전달 |
