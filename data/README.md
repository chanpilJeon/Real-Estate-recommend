# data/ — 수동으로 내려받는 원본 데이터

이 폴더의 파일은 용량이 크고 출처가 정부 사이트라 깃에 넣지 않습니다.
아래 안내대로 직접 내려받아 이 폴더에 두세요.

## 법정동코드 전체자료 (`legal-dong-codes.txt`)

지역 검색 기능의 기반 데이터입니다. **없으면 지역 검색이 동작하지 않습니다.**

1. https://www.code.go.kr 접속 (행정표준코드관리시스템)
2. 상단 메뉴에서 **법정동코드** 검색 또는 `주요코드 > 법정동코드` 이동
3. **법정동코드 전체자료** 의 `다운로드` 클릭 (`.txt` 파일, 약 3MB)
4. 받은 파일 이름을 **`legal-dong-codes.txt`** 로 바꿔서 이 폴더(`data/`)에 넣기
5. 터미널에서 `pnpm seed:region` 실행

파일 형식 (탭으로 구분, EUC-KR 인코딩):

```
법정동코드	법정동명	폐지여부
1100000000	서울특별시	존재
1111000000	서울특별시 종로구	존재
1111010100	서울특별시 종로구 청운동	존재
```

인코딩은 스크립트가 자동으로 판별합니다 (EUC-KR / UTF-8 모두 가능).
